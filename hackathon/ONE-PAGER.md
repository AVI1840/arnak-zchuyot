# סוכן מיצוי 360 — One Gov AI Agent
## ביטוח לאומי × AWS Hackathon 2026

---

## הבעיה

**2.4 מיליון מקבלי קצבאות** בביטוח הלאומי מפסידים בממוצע **₪15,000 בשנה** בזכויות שמגיעות להם ולא ממומשות.

הסיבות:
- זכויות פזורות בין 8+ משרדי ממשלה ורשויות
- אין מקום אחד שמרכז את כל מה שמגיע לאזרח
- האזרח לא יודע מה לשאול ואיפה לפנות
- תהליכי הגשה מורכבים ומרתיעים

**אימפקט לאומי:** ~₪36 מיליארד בשנה בזכויות לא ממומשות.

---

## הפתרון

**סוכן AI שמנהל שיחה חופשית עם האזרח**, מזהה את מצבו, סורק זכויות רוחבית בין כל המשרדים, ומלווה אותו מקצה לקצה — מזיהוי הזכות ועד ההגשה.

### 3 שכבות:

```
Citizen Agent (שיחה חופשית בעברית)
        ↓
מנוע מיצוי 360 (98 זכויות, 15 קצבאות, 8 קטגוריות)
        ↓
Agent Orchestration (סריקה רוחבית בין-משרדית)
```

## מה הסוכן עושה

| שלב | פעולה | דוגמה |
|------|--------|--------|
| 1 | מקשיב | "אני בן 70, מקבל קצבת זקנה, 80% נכות, גר בשכירות" |
| 2 | שואל | "האם אתה מקבל השלמת הכנסה?" |
| 3 | סורק | סריקה רוחבית: ביטוח לאומי, רשויות מקומיות, משרד הבינוי, רשות המים, קופות חולים |
| 4 | מציג | 28 זכויות עם הסבר "למה מגיע לך" + רמת ביטחון |
| 5 | מלווה | מסמכים נדרשים, טפסים, הגשה דיגיטלית, מעקב סטטוס |

---

## טכנולוגיות AWS

| שירות | שימוש |
|--------|--------|
| **Amazon Bedrock** | Agent orchestration + Claude model |
| **Knowledge Base** | RAG על מאגר זכויות + חקיקה + נהלים |
| **Lambda** | Tools: check_rights, get_documents, cross_ministry_scan |
| **DynamoDB** | פרופיל אזרח + session management |
| **S3** | מאגר מסמכים וטפסים |
