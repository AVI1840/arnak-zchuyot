## 1. Executive Summary

מסמך זה מהווה חוזה נתונים (Data Contract) רשמי עבור מערכת **"ארנק זכויות"** — כלי דיגיטלי המרכז 98 זכויות וגמלאות של המוסד לביטוח לאומי בממשק אחד נגיש וידידותי לאזרח.

### רקע

מערכת ארנק הזכויות פותחה כמענה לצורך מבצעי: ריכוז כלל הזכויות והגמלאות של הביטוח הלאומי במקום אחד, תוך מתן יכולת סינון, חיפוש והתאמה אישית לאוכלוסיות שונות. המערכת מבוססת על קובץ JSON סטטי המכיל את מאגר הזכויות המלא, ופועלת כאפליקציית צד-לקוח (Client-Side SPA) ללא תלות בשרתים חיצוניים.

### מטרות החוזה

| # | מטרה |
|---|------|
| 1 | הגדרת בעלות ואחריות על הנתונים |
| 2 | תיאום ציפיות בין גורמי התוכן לגורמי הפיתוח |
| 3 | הגדרת תהליכי עדכון ושחרור |
| 4 | עמידה בדרישות אבטחה ונגישות |
| 5 | הבטחת איכות נתונים לאורך זמן |

### נתונים מרכזיים

| פרמטר | ערך |
|--------|-----|
| מספר זכויות במאגר | 98 |
| פורמט נתונים | JSON |
| ארכיטקטורה | 100% Client-Side SPA |
| טכנולוגיה | React + TypeScript + Vite |
| תדירות עדכון צפויה | 2–4 פעמים בשנה (שינויי חקיקה) |
| סביבת הפעלה יעד | SharePoint 2013 (iframe) / Umbraco (עתידי) |

## 8. Security Considerations

### 8.1 הערכת סיכוני אבטחה

| מאפיין | הערכה | הסבר |
|--------|--------|-------|
| רמת סיווג מידע | **נמוך** | כל המידע ציבורי — זכויות פורסמו |
| אימות משתמשים | **לא נדרש** | אין מידע אישי |
| הרשאות | **לא נדרש** | צפייה בלבד, אין פעולות |
| תקשורת רשת | **אין** | אפליקציה סטטית — אין API calls |
| אחסון נתונים | **אין** | אין DB, אין cookies, אין localStorage |
| Attack Surface | **מינימלי** | Static files בלבד |

### 8.2 אמצעי הגנה

| אמצעי | סטטוס | הערות |
|--------|--------|--------|
| HTTPS | ✅ נדרש | בהתאם לסביבת Hosting |
| Content Security Policy | ✅ מומלץ | הגבלת מקורות scripts |
| Subresource Integrity | ✅ מומלץ | אימות תקינות קבצים |
| X-Frame-Options | ⚠️ לבדיקה | נדרש ALLOW עבור iframe |
| Input Sanitization | ✅ מובנה | React auto-escaping |
| npm Audit | ✅ נדרש | בכל Build — בדיקת vulnerabilities |

### 8.3 הגבלות SharePoint iframe

- יש לוודא שה-iframe source domain מוגדר כמהימן
- יש להגדיר `X-Frame-Options: ALLOW-FROM` או `Content-Security-Policy: frame-ancestors`
- אין העברת נתונים רגישים בין ה-iframe ל-parent page

### 13.2 פירוט: סוגי זכות לא מוגדרים (Invalid Benefit Types)

**תיאור:** נמצאו 3 סוגי זכות (benefit types) המופיעים ב-10 רשומות במאגר, אך **אינם מוגדרים ב-Consumer Schema** — כלומר, הם אינם מוכרים על ידי האפליקציה הצורכת את הנתונים.

| # | Benefit Type | מזהה | מספר רשומות מושפעות |
|---|-------------|-------|---------------------|
| 1 | `holocaust_families` | משפחות שואה | 4 |
| 2 | `righteous_gentiles` | חסידי אומות העולם | 3 |
| 3 | `blood_transfusion` | נפגעי עירוי דם | 3 |

**סה"כ רשומות מושפעות:** 10 מתוך 98 (10.2%)

### 13.3 השפעה

- הזכויות הללו **לא יוצגו** בממשק אם הסינון מבוסס על enum מוגדר
- משתמשים הזכאים לזכויות אלו **לא יראו אותן** בחיפוש לפי קטגוריה
- ממצא זה אינו שובר את המערכת, אך פוגע בשלמות המידע המוצג
